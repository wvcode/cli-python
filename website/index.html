O CLI que resolve o CSV problemático antes do seu script quebrar.

Converte, diagnostica, perfila e limpa CSV, Excel, JSON e Parquet: nulos, duplicidade, datas inconsistentes e texto que devia ser número, tudo detectado automaticamente. Também entende CSV com ;/cp1252, CPF/CNPJ e valores em R$, nativamente.

Detecta o que atrapalha antes de você perceber

info e clean abrem o arquivo e apontam os problemas, coluna por coluna, antes de qualquer análise.

NULOS · DUPLICIDADE

O óbvio, automático. Valores nulos, linhas duplicadas (inteiras ou por chave, como um ID) e inconsistência de capitalização ("Porto Alegre" / "PORTO ALEGRE") saem no primeiro diagnóstico.

TIPOS

Texto que devia ser número. --fix-types reconhece tanto 1,234.56 quanto 1.234,56 e converte para o tipo certo, sem confundir milhar com decimal.

DATAS

Qualquer formato comum. Colunas com dd/mm/yyyy, yyyy-mm-dd e outras variações viram ISO 8601 numa única passada.

CSV REGIONAL · DOCUMENTOS

Suporte nativo ao Brasil. CSV exportado pelo Excel em português (;, cp1252, 1.500 como mil e quinhentos) é detectado sozinho, a chave da NF-e é lida sem perder dígitos, e CPF/CNPJ são validados pelo dígito verificador. Em planilhas com várias abas, --sheet escolhe a aba.

Quatro comandos, um fluxo

Sem flags, clean só diagnostica — nada é gravado até você pedir.

convert

Converte entre CSV, JSON, JSONL, Excel, Parquet, Feather, Avro e SQLite. O formato é inferido pela extensão do arquivo.

datatool convert vendas.xlsx vendas.parquet

info

Abre um arquivo e aponta nulos, duplicidade, datas inconsistentes e texto que devia ser número.

datatool info clientes.csv

profile

Min, max, média, percentis e outliers nas colunas numéricas; cardinalidade e top valores nas categóricas.

datatool profile vendas.csv --key cpf

clean

Corrige o que o info encontrou: espaços, capitalização, duplicidade, nulos, datas, tipos, CPF/CNPJ.

datatool clean clientes.csv --fix-types --output limpo.csv

JSON pronto para script e CI

--format json troca a saída de texto por um documento versionado — o mesmo diagnóstico, em formato que um jq, um notebook ou um pipeline de CI conseguem ler.

--redact-values tira os valores de célula do relatório sem perder as contagens. Serve para colar a saída num chat de IA ou num ticket sem expor dado de cliente — o log de execução também nunca grava valores.

Um servidor MCP para agentes de IA

Claude Code, Claude Desktop, Cursor e outros agentes que falam MCP podem chamar info, profile, clean e convert direto, em vez de escrever código de análise do zero a cada conversa.

datatool_info datatool_profile datatool_clean_diagnose datatool_clean_apply datatool_convert

Todo caminho de arquivo fica restrito ao diretório passado em --root. redact_values vem ligado por padrão nas ferramentas — diferente do CLI — para valores de célula não trafegarem para o modelo sem pedido explícito.

pip install "datatool-cli[mcp]" 
{
  "mcpServers": {
    "datatool": {
      "command": "datatool-mcp",
      "args": ["--root", "/caminho/do/projeto"]
    }
  }
}

Instalação

Publicado no PyPI como datatool-cli; o comando é datatool. Requer Python 3.10 ou mais novo.

$ pip install datatool-cli
$ datatool info clientes.csv
